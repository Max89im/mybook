MyBook PWA — первый прототип (27.10.2026)

ЧТО РАБОТАЕТ
- Экран пяти демонстрационных рекомендаций (без OpenAI и без поиска Flibusta).
- Локальный список любимых книг, сохранение в localStorage.
- Импорт EPUB, чтение названия и автора из OPF.
- Загрузка собственной картинки, обрезка под 528x792, градации серого, надписи.
- Экспорт EPUB с заменой изображения, указанного в OPF как cover-image, либо добавлением нового.
- Кнопка открытия веб-интерфейса CrossPoint по указанному адресу.
- Установка на домашний экран iPhone при размещении по HTTPS.

ОГРАНИЧЕНИЯ
- Генерация обложек OpenAI пока НЕ подключена; используется выбранная картинка.
- Рекомендации демонстрационные, оценки ИИ нет.
- Скачивание книг с Flibusta и автоматическая передача CrossPoint НЕ реализованы.
- Сложные EPUB с отдельной HTML-страницей обложки могут показывать старую обложку в начале книги: первая версия меняет OPF cover-image, не все ссылки на старую картинку.
- ZIP собирается библиотекой JSZip; на очень больших книгах может требоваться память.
- Данные localStorage могут пропасть после очистки данных Safari.
- Для установки PWA требуется HTTPS (не file:// и не обычный http:// с Windows).

КАК ПРОВЕРИТЬ НА IPHONE (БЕЗ MAC)
1. Создать бесплатный репозиторий GitHub и загрузить в его корень все файлы из архива.
2. Settings > Pages > Build and deployment > Deploy from a branch > main / (root) > Save.
3. Дождаться появления адреса вида https://USERNAME.github.io/REPOSITORY/ .
4. Открыть адрес на iPhone в Safari.
5. Поделиться > На экран «Домой» > Добавить.
6. Открыть MyBook с домашнего экрана, проверить «Мои вкусы» и импорт EPUB.
7. В «Xteink» ввести URL, показанный CrossPoint при запуске передачи по Wi-Fi.

ВАЖНО: Не вводить OpenAI API-ключ в этот прототип. GitHub Pages — публичный хостинг статических файлов. Личные EPUB в этот хостинг не загружаются: они обрабатываются на устройстве.

РЕКОМЕНДАЦИЯ ДЛЯ ТЕСТА
Использовать копию EPUB и проверить, что новая обложка видна на самом Xteink X3. Сложные EPUB требуют расширенной обработки cover.xhtml.
